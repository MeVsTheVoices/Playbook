Rolling It Out

1

Merge, do not replace. Open the Tailscale admin console, go to Access Controls and add the generated sections (tagOwners, grants, ssh, autoApprovers, tests). Grants and legacy acls can coexist. Keep Tailscale's default allow-all grant until the rack works, then delete it.

2

Tags before auth keys. A tag must exist in tagOwners before a node can use it, and an auth key (or OAuth client) must be created with the same tags the node advertises. Each board advertises its own tag plus the homelab tag, set by the SD form and the Node Ops Tailscale module.

3

Subnet routes. Auto-approval only fires when a route is first advertised. If a node already advertises it, stop advertising and advertise it again.

4

SSH needs two things. A network rule to port 22 (the admin grant covers it) and an ssh rule. The node must also run tailscale up --ssh.

5

Save and read the result. Tailscale runs the tests when you save and rejects the change if one fails, so a broken rule shows up before it reaches the rack. A reimaged node gets a new tailnet IP; tags keep the rules working.
